# MoneyTrack - Personal Expense & Money Manager

A complete mobile-friendly personal finance tracker built with HTML, CSS and Vanilla JavaScript.

## Features

- Dashboard with total balance, income, expenses and transaction count
- Cash, UPI, Bank and Other account tracking
- Income, Expense, Money Given, Money Received and Transfer transactions
- Transfer money between accounts without counting it as income/expense
- People/contact management
- Track money given and received by person
- Transaction search and filters
- Category and monthly reports
- Dark mode
- JSON backup and restore
- CSV transaction export
- LocalStorage persistence
- Responsive mobile bottom navigation
- Edit/delete transactions and people
- Starting balances

## Run

Extract the ZIP and open `index.html` in a modern browser.

No backend, database or installation is required.

## Important

All data is stored in the browser's LocalStorage. Clearing browser site data can remove your records, so use **Settings → Export JSON** for backups.
